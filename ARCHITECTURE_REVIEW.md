# Architecture Review
Generated: 2026-09-20T18:17:55.436Z
Score: 52/100

## Summary
A React/TDS mini-app with a sensible layering (components, lib, pages) and thorough defensive SDK wrappers. However, it carries a leftover template layer (contract.ts, utils.ts, log.ts, storage.ts) that conflicts with the real domain layer. Helpers are copy-pasted across pages, and import styles are mixed.

- [structure] The storage layer is inconsistent. core.ts mixes low-level safeGet/safeSet with order listing. Pages import from storage/core (listOrders), storage/orders (getOrders) and storage/settings directly. Move listOrders/getOrder into orders.ts and keep core.ts as low-level I/O only. Pick one accessor name. Centralize limits in types.ts or constants.ts. Unify the review flag.
- [consistency] Import style is mixed. Home.tsx, and the components, use relative paths ('../lib/...'). The other pages and lib files use the '@/' alias. TossRewardAd uses '@/'. Quotes also differ (single in Home/App/main, double elsewhere). Error handling varies: the storage layer returns StorageResult, some functions swallow errors, and some silently return defaults (getItem returns null, setItem can throw). — Files: src/pages/Home.tsx, src/App.tsx, src/components/Amount.tsx, src/components/CountUp.tsx, src/lib/storage.ts / Fix: Enforce the '@/' alias and add ESLint/Prettier rules. Standardize error handling on a Result type or on never-throw.

### Suggestions
- [structure] PageShell hacks module namespaces with import * and pick() to work around test mocks. This puts test concerns in production code. TossPurchase is a component that talks to a backend concept but is unused. Dev artifacts (__TdsGallery) sit in pages/. Domain components (SummaryHero, Card) sit next to SDK wrappers (AdSlot, TossPurchase, TossRewardAd) in components/. Business logic (savings.ts, summary.ts) is mixed with SDK adapters (share.ts, review.ts, analytics.ts) in lib/. — Files: src/components/PageShell.tsx, src/pages/__TdsGallery.tsx, src/lib/share.ts, src/lib/review.ts, src/lib/analytics.ts, src/lib/summary.ts / Fix: Fix the test mocks instead (use a shared mockAnalytics helper) and simplify PageShell. Split lib/ into domain/, platform/ (SDK adapters) and storage/. Group components into ui/ and sdk/. Move the gallery under dev/.
- [consistency] Naming is inconsistent. The same concept appears as savable/savedKrw, and 'Order'/'DeliveryOrder'. The names getOrders/listOrders are used inconsistently. There is a mix of KRW-suffixed and unsuffixed money fields. The BottomCTA.tsx file exports SubmitFooter, which does not match the file name. The __TdsGallery and __getRecords double-underscore names are used non-uniformly. Home.tsx is default-exported while components use named exports. — Files: src/components/BottomCTA.tsx, src/lib/savings.ts, src/lib/contract.ts, src/lib/types.ts / Fix: Adopt one glossary. Rename the file to match its main export (or split it). Use one export convention.
