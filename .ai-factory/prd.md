# DeliveryTipTally

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
이번 달 배달팁으로만 얼마 냈는지 아세요? 주문 한 번 적을 때마다 쌓이는 배달비 누적 계산기

## Problem
배달앱을 쓰면 배달팁과 최소주문금액 채우기 때문에 지출이 커지지만, 월 합계를 확인하기 어렵다.

## Target Users
배달을 자주 시키는 1인 가구, 자취생, 20-30대 직장인

## Core Features
1. 주문 금액, 배달팁, 플랫폼을 10초 안에 기록
2. 월 누적 배달팁과 주문 횟수 표시
3. 직접 픽업했다면 아꼈을 금액 시뮬레이션
4. 최소주문금액 맞추려고 추가한 금액 별도 집계
5. 월 배달비 목표 설정과 초과 경고
6. 월간 리포트 공유 카드

## Monetization
- Model: ads
- Estimated MRR: 64
- Reasoning: 월간 리포트 공개 시점에 리워드 광고를 건다. 주문 기록 목록 사이에는 배너를 넣는다. 주문할 때마다 기록하므로 주 단위 재방문이 생긴다.
